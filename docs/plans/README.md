# Plans

AI agents (Claude Code, Codex, Copilot) save multi-step plans here before building, so any later
session or a different agent can read the plan and continue.

- One file per task: `YYYY-MM-DD-short-name.md`.
- Include: goal, files to change, steps, how it will be checked, and what is still open.
- Update the file as steps finish; mark it **Done** at the top when the work is merged.
- No secrets, keys or customer details in plans (this repo is public).
